Privacy policy

For rclone-t7. Last updated 17 October 2026.

Who uses it

rclone-t7 is a personal backup setup used only by its owner (omertekin2002), with the owner's own Google account. It is not offered to anyone else.

What it can access

It uses Google's drive.file permission, so it can only see and change files and folders that it created in the owner's Google Drive. It cannot see any other files in that Drive.

What it does

It uploads backup copies of files from the owner's own drive. When a file is deleted or changed on that drive, the older copy in Google Drive is moved to a backup folder instead of being removed.

Where data is kept

Files go only to the owner's Google Drive. The Google sign-in token is stored only on the owner's own computer. No data is sent anywhere else.

Sharing

No data is collected, sold or shared with anyone. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
